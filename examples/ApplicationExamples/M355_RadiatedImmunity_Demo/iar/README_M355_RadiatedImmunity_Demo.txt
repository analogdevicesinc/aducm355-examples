The 'M355_RadiatedImmunity_Demo' project is an application demo for CN0425
using the ADuCM355 microcontroller and the Analog Devices EVAL-ADuCM355QSPZ
evaluation board.

Example functionality:

Clock Settings:

CPU     = 26.00 MHz (HFOSC)
HCLK    = PCLK = 26 MHz

Demonstrates robust electrochemical measurement operation under noisy
	 electromagnetic environments
Implements CN0425 reference design measurement and processing flow
Outputs measured data and status information via UART
UART settings: 230400 baud, 8 data bits, no parity, 1 stop bit
