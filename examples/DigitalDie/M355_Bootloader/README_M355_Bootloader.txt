The 'M355_Bootloader' project demonstrates a bootloader/application update flow
on the ADuCM355 microcontroller.

Example functionality:
 - Provides a bootloader image and a companion application image
 - Demonstrates control handoff from bootloader to application
 - Supports firmware update workflow used by ADuCM355 examples

Project structure:
 - Bootloader project and source files
 - Example application project used with the bootloader

Build and debug targets are provided in the IAR workspace for development use.
